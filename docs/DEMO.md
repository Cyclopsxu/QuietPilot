# Step 6 演示手册

当前状态：操作手册与双屏自动录制脚本已准备；完整五段演示、三轮持续中文输入及两路录像尚未验收。不要使用上游 shadowauto.mp4 充当本分支视频。

## 准备

- 构建与 Lint、`./scripts/test-interaction-regressions.sh` 全通过，记录 APK SHA256；覆盖安装控制端并重启 shell 前确认没有未完成任务。
- 模型配置使用已登录的机主账户；在配置页逐角色测试连接并记下服务端 model。不得在录像展示密钥页。准备网络、电量和免打扰，关闭可能露出私人信息的通知。
- 保持微信已登录，消息仅发文件传输助手；大众点评准备可公开的店铺页。瑞幸/美团提前确认能到规格或订单确认页，不尝试支付、验证码或人脸验证。
- 技能页先导出/备份对应 App 技能，再清除测试技能，避免删除用户其他技能。测试结束可恢复备份。三个测试消息为测试1、测试2和测试3，不混入私人内容。
- 隔离不足的手机默认阻止后台；仅机主已选择兼容实验时按该模式测，视频展示真实限制。

## 双屏录制与单独兼容性检查

本机已核对 scrcpy 5.0.1 的 `--display-id`、`--window-title`、`--record`、`--no-control` 与 `--no-audio`。参见 [官方录制说明](https://github.com/Genymobile/scrcpy/blob/master/doc/recording.md)及[指定显示屏](https://github.com/Genymobile/scrcpy/blob/master/doc/video.md#display)。

```sh
export ANDROID_SERIAL='<adb devices 中的目标设备>'
./scripts/record-demo.sh ../docs/validation/step6-recording-01
```

先启动脚本再提交任务；脚本立即录主屏，监听新日志 `VIRTUAL_DISPLAY_READY` 自动启动每个任务的虚拟屏录制。输出 main.mp4、任务 ID-vd.mp4、各路日志、scrcpy 版本和 timeline.jsonl。两路使用独立端口和 `--force-adb-forward`；本机默认 reverse 并发预检曾发生主屏连接失败，失败日志保留。虚拟屏销毁时该路自动退出，下个任务会新建文件；保留结果或等待人工时屏幕尚未销毁，不能把“模型完成”当作录制已结束。Ctrl+C 正常封装文件。使用只读投屏，不同步剪贴板、不从电脑点击手机。

先用公开计算器页单独检查：录制前后各抓图/读控件并保存焦点采样；确认第二路连接后可继续点击、结果能变化、截图不黑、控件不丢失、焦点不离主屏。两路硬件编码可能受手机并发限制，失败需记录，不得默认兼容。结果记录在 evidence/demo-path/README.md；未验证时不写通过。

## 出错重来

登录/验证码/付款交给机主，记录 WAITING_USER，不尝试绕过。App 不兼容保留截图和日志，并按任务指定替代方案重跑。停止失败任务，等待 finalized、虚拟屏释放后使用新 taskId；保留失败样本。重复动作必须看到 LOOP_DETECTED，第二次只独立验收或明确失败，不删日志伪装一次成功。

人工并行三轮按 [采集步骤](../scripts/isolation-concurrency-test.md)执行。额外 F8 采集依现场工具，本仓库没有默认 F8 录制功能。
