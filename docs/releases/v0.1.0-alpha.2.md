# 隐航 QuietPilot v0.1.0-alpha.2 — 输入空闲门禁与保页交接

本版更新微信视觉兼容输入、主屏输入空闲门禁及步数耗尽后的人工交接。仍为开发预览版，非原生独立焦点或全程无打扰认证。

## 下载和升级

- **控制端 APK**：`QuietPilot-v0.1.0-alpha.2-controller.apk`，Android 10 / API29+。
- **完整部署 ZIP**：`QuietPilot-v0.1.0-alpha.2-android-arm64.zip`，含控制端、shell 后台、ARM64 OCR、启动脚本、说明和许可证；首次安装及更新后台均推荐使用。
- **完整性**：`SHA256SUMS.txt`；构建来源、签名及检查信息见 `release-manifest.json`。

只更新控制端 APK 不会更新正在运行的 shell 后台。请先完成或取消旧任务，再按 [INSTALL.md](https://github.com/Cyclopsxu/QuietPilot/blob/v0.1.0-alpha.2/docs/INSTALL.md) 上传新 shell/OCR 并重新启动；重启后台不能保留仍在旧虚拟屏中的实时页面。

两个 APK 的 versionCode 均为 3，包名保持 `com.silentauto.controller` / `com.silentauto.shell`。使用非 debuggable release 构建，沿用既有开发证书签名；不分发签名密钥。配套 OCR 仅 ARM64，不包含任何用户 API Key。与已有安装证书不同会无法覆盖，勿直接卸载丢失配置。

## 本版变化

- 微信无障碍树不可读时，正式任务引擎可用截图、本地 OCR、可见菜单粘贴及复制全文核对完成兼容输入。输入、草稿和已发气泡核对仍会短暂借用全局焦点并归还。
- 借焦点前要求主屏应用可读、键盘收起、无聚焦编辑框，并连续确认空闲 2 秒。编辑、近期触摸/按键或读数缺失时等待，不消耗自动步数；等待结束后重新观察。借用期间在检查点发现主屏新操作会中止并归还焦点。
- 自动操作仍上限 25 步。耗尽后仅做一次只读检查，然后保留原页等待人工接管；检查失败也保留，不直接回收或冒充成功。转到主屏后可“结束接管”，不再把原页搬回后台。
- 修复“不保留页面”未被识别而误走结果交接验收的问题。
- 中英文 README 增加 [53 秒双屏实录](https://github.com/Cyclopsxu/QuietPilot/blob/v0.1.0-alpha.2/docs/evidence/coffee-dual-screen/coffee-handoff-53s.mp4)：语音美团追加及第 25 步人工交接，5 倍速、近似同步、已遮挡收货信息，未付款。

## 检查与实测范围

- 发布检查覆盖 Android 构建/Lint、主机回归、签名、版本/包信息、ARM64 OCR 和 ZIP 完整性；源码工作区构建已部署测试。打包后的 release APK 未覆盖安装到实体手机，不能将工作区样本当作发布二进制的全路径复测。
- Mate40Pro / API31 专用编辑页：真实系统键盘展开、合成 ASCII 输入时，微信任务等待至少 8 秒，0 次借焦点或主屏失焦，步骤和模型调用不增长；不是持续真人拼音测试。
- 专用无音轨 Android VideoView：约 67 秒样本中，3 次借用均归还（约 6.1 / 6.5 / 4.6 秒），无暂停或停止播放记录，播放进度持续前进。
- 文件传输助手只发送 1 条编号消息，草稿和已发气泡复制全文相等。原发送任务末尾因“不保留页面”误判而 FAILED；该规则已修复并部署，未重发第二条消息冒充完整成功重测。纯本地 OCR 随后确认会话标题、完整原文及唯一右侧编号。

## 已知限制

- 兼容模式仍借用全局焦点；键盘开着但暂时停打、收起键盘但输入框仍聚焦时也会等。第三方播放器、音频连续性、真人中途抢占及零瞬态干扰未验证，某些 App 可能响应失焦暂停。
- 本机微信只读查询遇到空树时，无法核实的点击仍被门禁阻止；没有放宽保护。
- 隔离能力不足时默认阻止后台；`--allow-unverified-isolation=true` 是明确选择的兼容实验，不能补齐系统能力。锁屏暂停保留，解锁重新观察；不支持进程强杀/重启后恢复原会话。
- 登录、验证码、支付和身份验证由本人处理，不自动付款。技能仍可能救援或回退模型。
- RPC 本机回环未鉴权；页面、截图、音频等可能按任务需要发送给用户配置的模型服务，不是专用密钥保险库。

保留上游 android-notes/ShadowAuto 的 Apache-2.0、NOTICE 与归属。历史失败和旧录像保留，不把单次样本提升为跨设备兼容保证。
