# 隐航 QuietPilot v0.1.0-alpha.1 — 开发预览版

首个 GitHub 预览包。运行真实 Android App 的后台虚拟屏自动化原型，支持文字/语音、当前屏幕上下文、技能学习与救援、只读查询、结果验收、人工边界交接及锁屏暂停后续跑。

## 下载和安装

- **控制端 APK**：`QuietPilot-v0.1.0-alpha.1-controller.apk`，Android 10+。
- **首次完整部署**：下载 `QuietPilot-v0.1.0-alpha.1-android-arm64.zip`，包含 APK、shell 后台、ARM64 OCR、启动脚本、安装说明及许可证。
- **完整性**：`SHA256SUMS.txt`。签名与构建检查见 `release-manifest.json`。

**只安装 APK 无法启动完整自动化。**需要电脑 ADB、USB 调试授权，将 ZIP 内 shell/OCR 上传并通过 `app_process` 启动。手机重启或后台被杀后需重新启动。解压 ZIP 后按 `INSTALL.md` 操作。

在线安装说明：https://github.com/Cyclopsxu/QuietPilot/blob/v0.1.0-alpha.1/docs/INSTALL.md

包名 `com.silentauto.controller`，versionCode 2。使用非 debuggable release 构建及开发证书签名，非生产签名；与已有安装证书不同会无法覆盖，勿直接卸载丢失配置。配套 OCR 仅 ARM64。需要用户自己的 executor/verifier/intake API 配置，不包含任何 API Key。

## 验证与已知限制

- 发布检查覆盖构建、Lint、主机回归、APK 签名/包信息与 ZIP 完整性；未将本版 APK 覆盖安装到实体手机，不宣称完整业务已复测。
- 主要历史实测设备为 Mate 40 Pro / HarmonyOS 4.2 / API 31，不保证所有 Android 10+ 手机兼容。
- 全程焦点/IME 隔离尚未认证，缺能力默认阻止执行；显式兼容实验不补齐能力，不能保证不打扰主屏。
- 锁屏时暂停保留，解锁后重新观察；不支持锁屏持续操作、进程强杀或重启后的原会话恢复。
- 微信发送未通过，部分 App 可能启动退出或控件不可读；完整店铺地址上下文与咖啡成功连续双屏录像仍缺。
- 登录、验证码、支付和身份验证由本人完成，自动流程停在人工边界，不自动付款。
- 技能仍可能救援/回退模型，未证明整体提速。
- RPC 本机回环未鉴权；配置不属于专用密钥保险库。页面文字、截图、音频与上下文可能发给用户已配置的模型服务。
